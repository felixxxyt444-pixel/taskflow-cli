# TaskFlow CLI

Консольный менеджер задач (To-Do) на Python — учебный проект к практической работе №9
«Управление проектом и командная работа».

**Цель продукта:** дать студенту простой инструмент, чтобы добавлять, отслеживать и завершать учебные задачи из терминала.

## Команда
| Участник | Роль |
|---|---|
| [ФИО студента 1] | Product Owner, разработчик |
| [ФИО студента 2] | Scrum Master, разработчик (ревьюеры чередуются) |

## Как запустить
```bash
python -m taskflow add "Сдать отчёт" --priority high
python -m taskflow list
python -m taskflow done 1
python -m taskflow delete 1
python -m unittest discover tests
```

## Правила работы с Git
- **Ветки:** `main` — стабильная, `develop` — интеграция, `feature/<номер-задачи>-<кратко>` — разработка.
- **Коммиты:** `префикс: описание (TASK-N)`, префиксы `feat`, `fix`, `docs`, `refactor`, `test`.
  Пример: `feat: добавить функцию удаления задачи (TASK-5)`.
- **Прямые коммиты в `main` и `develop` запрещены** — только через pull request с ревью.
- Задачи ведутся в GitHub Projects (доска) и Issues (backlog).
